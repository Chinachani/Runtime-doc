# QQ Runtime

QQ 官方机器人运行时框架（商业发行版）。基于 Python 3.12 + FastAPI + SQLite，
内置管理台、授权体系、插件沙箱与积分/支付/媒体等能力。

> 本仓库仅用于发布**插件开发文档**、**部署教程**、**更新日志**与**发行公告**。
> 框架以编译加固的 Docker 镜像分发，不在此处提供源码。

## 获取框架

镜像发布在 GHCR（首次发行后可用）：

```bash
docker pull ghcr.io/chinachani/qq-runtime:latest
```

安装与配置见 [docs/部署教程.md](docs/部署教程.md)。

## 授权与版本

- 框架按授权级别开放功能；未授权实例仅可执行诊断指令。
- 管理台「关于/更新」会自动检查本仓库的 Release 获取新版本与更新日志。
- 商业插件按 `[license]` 授权块与厂商签名发放。
