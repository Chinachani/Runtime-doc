本文档将指导您从零开始开发一个功能完备的第三方插件。

## 1. 插件架构与安全模型

QQ Runtime 采用沙箱隔离机制保护宿主环境：

- **隔离运行**：每个外部插件作为独立 Python 子进程运行，通过受限的 `PluginContext` 与 Runtime 主进程通信；
- **权限最小化**：插件必须显式声明所需的权限（`permissions`）与能力（`capabilities`），未经声明的系统调用（如网络外联、发送消息等）将被沙箱拦截；
- **目录隔离**：插件只能读写自身数据目录（`data/plugins/<plugin_id>/`），严禁访问数据库文件、宿主环境变量及其他插件的私有数据。

## 2. 快速开始：最小插件实现

一个标准插件包含一个目录，最简情况下只需包含 `plugin.toml` 和一个入口 Python 脚本：

```text
plugin.hello/
├── plugin.toml           # 插件清单与权限声明
└── hello.py              # 业务入口代码
```

### 第一步：创建 `plugin.toml`

```toml
dependencies = []
permissions = ["chat.send"]
capabilities = ["chat.send"]

[plugin]
id = "plugin.hello"
name = "打招呼插件"
version = "1.0.0"
entrypoint = "hello:setup"

[[commands]]
name = "hello"
category = "demo"
description = "向机器人打招呼"
```

### 第二步：编写入口脚本 `hello.py`

```python
"""打招呼插件入口脚本。"""

def setup(context):
    async def handle_hello(msg_ctx, args):
        sender = getattr(msg_ctx, "sender_id", "朋友")
        return f"你好，{sender}！欢迎使用 QQ Runtime。"

    # 注册命令
    context.register_command(
        "hello",
        handle_hello,
        category="demo",
        description="向机器人打招呼",
    )
    return None
```

### 第三步：打包与安装测试

在插件目录下将所有文件压缩为 ZIP 包（注意不要包含外层父目录）：
```bash
zip -r ../plugin.hello.zip plugin.toml hello.py
```
打开机器人管理台：**「插件管理」 ➔ 「上传插件包」 ➔ 选择 ZIP 上传 ➔ 启用插件**。在群内发送 `/hello` 即可看到回复。

## 3. 配置清单：plugin.toml 详解

`plugin.toml` 是插件的身份标识与安全清单，放置于插件根目录：

```toml
# ================= 顶层依赖与权限 =================
dependencies = []                           # 外部 pip 依赖（须在 Runtime allowlist 内）
permissions = ["chat.send"]                 # 管理接口权限 (RBAC)
capabilities = ["chat.send", "network"]     # 进程沙箱能力
builtins = ["runtime.pay"]                  # 依赖调用的内置模块（可选）

# ================= 插件元信息 =================
[plugin]
id = "plugin.translator"                    # 唯一 ID：字母开头，3-64 位 [a-zA-Z0-9_.-]
name = "智能翻译服务"                       # 展示名称
version = "1.0.0"                           # 遵循语义化版本 (SemVer)
entrypoint = "translator:setup"             # 入口模块:入口函数

# ================= 注册指令列表 =================
[[commands]]
name = "fy"                                 # 指令名称（群内发送 /fy 触发）
category = "utility"                        # 类别：ai / utility / tools / entertainment
description = "文本智能翻译"                # 描述信息

[[commands]]
name = "fye"
category = "utility"
description = "英汉快速互译"
```

### 常见权限与能力对照表

| 能力 / 权限 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| `chat.send` | 允许插件主动或被动向 QQ 频道/群聊发送消息 | 几乎所有需要交互的插件 |
| `network` | 允许插件发起外部网络 HTTP/WebSocket 请求 | 调用第三方外部 API、大模型接口等 |
| `points.manage` | 允许读取和扣减用户积分 | 付费增值服务、绘图积分等 |
| `plugins.manage` | 插件管理与自省能力 | 运维与系统辅助类插件 |

## 4. 入口函数与生命周期

插件入口必须导出一个形如 `setup(context)` 的函数：

```python
import logging

logger = logging.getLogger("plugin.demo")

class DemoService:
    def __init__(self, context):
        self.context = context

    async def close(self):
        """插件停用或卸载时自动调用，用于释放资源、关闭网络连接。"""
        logger.info("插件正在退出，释放长连接...")

def setup(context):
    """
    context 是受限的 PluginContext 实例。
    返回带 close() 的对象实例，在插件停用时 Runtime 会自动调用其 close()。
    """
    service = DemoService(context)

    # 注册命令
    context.register_command("test", service.on_test)
    
    return service
```

## 5. 消息处理与命令注册

### 命令注册：`context.register_command`

```python
async def on_echo(ctx, args: list[str]):
    """
    ctx: MessageContext 消息上下文对象
    args: 用户输入的参数列表（按空格分词）
    """
    content = " ".join(args).strip()
    if not content:
        return "请输入要回显的内容，例如：`/echo 你好`"
    return f"回显：{content}"

context.register_command("echo", on_echo, category="tools", description="文本回显")
```

### 事件监听：`context.register_event_listener`

除了通过 `/command` 触发外，插件还可以监听全局 QQ 消息事件：

```python
async def on_message(event):
    raw_text = str(event.get("content") or "")
    if "天气" in raw_text:
        # 处理逻辑...
        pass

context.register_event_listener("message.create", on_message)
```

## 6. Markdown 卡片与按钮矩阵

QQ Runtime 原生支持丰富的 **原生 Markdown 卡片** 与 **可点击交互按钮矩阵**。只需返回 `runtime.models.Card` 对象即可：

```python
from runtime.models import Card

async def on_menu(ctx, args):
    title = "🎨 绘图功能菜单"
    content = (
        "### 欢迎使用 AI 绘图服务\n\n"
        "请点击下方按钮选择您需要的操作：\n"
        "- 发送 `/dg draw <提示词>` 直接生图\n"
        "- 发送 `/dg balance` 查询积分余额\n"
    )
    
    # 构建按钮矩阵 (每行一个数组)
    rows = [
        [
            {"text": "🖼️ 立即画图", "action": "/dg draw 一只可爱的柴犬", "style": "primary", "fill": True},
            {"text": "💰 查余额", "action": "/dg balance"},
        ],
        [
            {"text": "⚙️ 偏好设置", "action": "/dg settings"},
            {"text": "📖 帮助手册", "action": "/dg help"},
        ]
    ]

    return Card(title, content, rows=rows)
```

## 7. 数据存储与持久化

每个插件拥有独立的持久化数据目录，可通过 `context.data_dir` 获取（该目录在容器升级、插件热重载时均会持久保留）：

```python
import json
from pathlib import Path

def get_storage(context):
    data_dir = Path(context.data_dir)
    data_dir.mkdir(parents=True, exist_ok=True)
    db_file = data_dir / "records.json"
    
    # 读写文件
    if db_file.is_file():
        records = json.loads(db_file.read_text(encoding="utf-8"))
    else:
        records = {}
        
    return records
```

## 8. 定时任务与网络请求

### 发起网络请求（必须声明 `capabilities = ["network"]`）

推荐使用内置的异步 HTTP 客户端 `httpx`：

```python
import httpx

async def fetch_weather(city: str) -> str:
    async with httpx.AsyncClient(timeout=10.0) as client:
        resp = await client.get(f"https://api.example.com/weather?city={city}")
        if resp.status_code == 200:
            return resp.json().get("summary", "无天气数据")
        return "查询接口超时"
```

### 定时周期任务：`context.register_cron`

```python
async def daily_report():
    logger.info("执行每日早间播报任务...")

# 每天早上 8:00 自动执行
context.register_cron("daily_report", "0 8 * * *", daily_report)
```

## 9. 独立 Web 管理页面开发

如果您的插件需要可视化后台配置界面，可以在插件包内提供 `pages/` 目录：

```text
plugin.my_tool/
├── plugin.toml
├── main.py
└── pages/
    ├── index.html        # 管理面板前端
    ├── app.js            # 前端交互逻辑
    └── style.css         # 样式表
```

### 前端与插件后端的数据通信

管理台加载插件页面时，采用安全 iframe 隔离（沙箱 CSP 保护）。前端与插件交互通过标准 `window.postMessage` 消息桥通信：

```javascript
// pages/app.js 示例
window.addEventListener("message", (event) => {
  const { action, payload } = event.data || {};
  if (action === "init_data") {
    console.log("收到初始化配置：", payload);
  }
});

// 向插件后端发送 RPC 请求
function callPluginAction(actionName, data) {
  window.parent.postMessage({
    type: "plugin_action",
    action: actionName,
    data: data
  }, "*");
}
```

## 10. 本地打包与测试

编写完插件后，准备交付：

1. **排除无关文件**：请勿将 `__pycache__`、`.git`、测试用例打包进发布 ZIP 包中；
2. **规范文件布局**：`plugin.toml` 必须位于 ZIP 包的顶级根目录（不能嵌套在多层文件夹里）；
3. **在管理台验证**：
   - 打开控制台 **「插件管理」** ➔ **「上传插件包」**；
   - 验证启用、停用、以及各项指令返回是否正常；
4. **提交上架**：
   - 测试无误后，参考 [《插件上架指南》](插件上架指南.md) 一键申请上架到官方插件市场。
